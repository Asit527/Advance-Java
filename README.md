# Advance Java Backend Workspace

A comprehensive workspace containing modular backend applications, microservices, and architectural implementations. This repository serves as a centralized hub for advanced Java development, focusing on scalable system design and industry-standard practices.

## 🚀 Key Projects

* **E-Commerce Product Service:** A scalable backend clone built to handle product cataloging, search functionality, and inventory management.
* **Booking System Application:** Core backend logic for reservation management, implementing robust JDBC operations, relational database schemas, and structured package layering (`com.rapido.booking`).
* **Spring Boot Modules:** Various microservices demonstrating dependency injection, REST API design, and authentication flows.

## 🛠️ Tech Stack & Tools

* **Core Language:** Java 
* **Framework:** Spring Boot
* **Build Lifecycle:** Maven
* **Database & Persistence:** SQL, JDBC, Relational Schema Design
* **Environment:** macOS / Unix

## 📂 Repository Structure

The workspace is organized into individual Maven projects and independent modules. Each directory represents a distinct service or architectural concept, allowing for isolated testing and development. 

## ⚙️ Setup & Execution

To run any of the individual modules locally:
1. Clone the repository: `git clone <your-repo-url>`
2. Import the root directory into your IDE (Eclipse/IntelliJ) as "Existing Maven Projects".
3. Allow Maven to resolve dependencies via `pom.xml`.
4. Run the respective `Application.java` file containing the `main` method.
